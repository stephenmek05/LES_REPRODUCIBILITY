# Raw TRY data

This directory contains the raw TRY dataset required by the reproducibility workflow.

File required by the analysis:

`49929.txt`

TRY request: `49929`.

The raw TRY data are subject to the terms and conditions of the TRY Plant Trait Database and are not redistributed as part of the reproducibility package.

To reproduce the analysis, obtain the corresponding TRY dataset and place the downloaded file here as:

`data/raw/49929.txt`

Do not rename the file unless the corresponding path in `R/LES_full_analysis.R` is also changed.
