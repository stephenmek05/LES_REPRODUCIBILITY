# Between categories and continua: growth-form organization in global leaf economics spectrum space

## Reproducibility package

This repository contains the analysis workflow, processed data, statistical results, figures, tables, and computational environment information associated with the manuscript:

> Between categories and continua: growth-form organization in global leaf economics spectrum space

The complete analysis is implemented in `R/LES_full_analysis.R`.

## Project structure

- `R/` — analysis script.
- `data/raw/` — raw TRY data required to run the analysis. The raw TRY dataset is not redistributed with this package.
- `data/processed/` — processed datasets, fitted models, statistical results, and intermediate analysis products.
- `figures/` — manuscript figures and supplementary figures.
- `tables/` — manuscript tables.
- `environment/` — R session information used for the analysis.
- `checksums/` — files for verifying reproducibility of key outputs.

## Data source

The analysis uses data obtained from the TRY Plant Trait Database, version 6.

TRY request: `49929`.

The raw TRY data are subject to the terms and conditions of the TRY database and are therefore not redistributed as part of this reproducibility package.

To reproduce the analysis, obtain the corresponding TRY dataset and place the resulting file at:

`data/raw/49929.txt`

The analysis script expects this exact relative path.

## Software environment

The analysis was developed and executed using R 4.5.2.

Package and session information used for the analysis is recorded in:

`environment/sessionInfo.txt`

## Running the analysis

1. Open `LES_REPRODUCIBILITY.Rproj` in RStudio.
2. Obtain the TRY data corresponding to request `49929` and place `49929.txt` in `data/raw/`.
3. Ensure the required R packages are installed. Package versions used in the analysis are documented in `environment/sessionInfo.txt`.
4. From the project root, run:

```r
source("R/LES_full_analysis.R")
```

The script creates the processed datasets, statistical results, fitted model objects, figures, and tables used in the analysis.

## Main analyses

The workflow includes:

- construction of the leaf economics spectrum (LES) trait dataset;
- principal component analysis of LES traits;
- growth-form comparisons in LES space;
- robustness analyses;
- PERMANOVA and PERMDISP;
- phylogenetic analyses;
- phylogenetic generalized least squares (PGLS);
- mixed-effects modelling;
- Bhattacharyya-distance analyses;
- assessment of filtering bias; and
- generation of manuscript and supplementary figures and tables.

## Expected outputs

Running `R/LES_full_analysis.R` should regenerate the files contained in:

- `data/processed/`
- `figures/`
- `tables/`

The exact files generated by the workflow are documented by the project directory structure.

## Reproducibility verification

The workflow has been tested from a fresh RStudio session using the project root as the working directory.

The master script can be executed with:

```r
source("R/LES_full_analysis.R")
```

The analysis uses explicit random seeds for stochastic procedures where required, and the current workflow has been tested for deterministic reproduction of the principal statistical outputs.

## Notes on warnings

Some warnings may appear during execution because of formatting and taxonomy issues in the upstream TRY data and taxonomic backbone. These were inspected during workflow validation and do not prevent successful completion of the analysis.
